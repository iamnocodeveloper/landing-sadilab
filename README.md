# landing-sadilab

Landing de demostración para **Laboratorio Clínico & Consultorios Médicos SadiLab** (Cuenca, Ecuador).

Sitio estático de una sola página (`index.html`, CSS y JS inline), mobile first, con:

- Presentación y servicios (laboratorio clínico, consulta médica, toma de muestras)
- Agenda demo interactiva con los horarios reales del negocio
- Consulta demo de resultados (cédula / código de orden)
- Horarios de atención, testimonios (62 reseñas 5.0 en Google) y ubicación
- Botones de contacto que abren WhatsApp (+593 96 340 4408) con mensaje precargado

## Despliegue

Se construye con un `Dockerfile` de dos líneas (`nginx:alpine` + copia de los archivos) y se publica en EasyPanel desde este repositorio.

## Nota

Sitio de referencia hecho por Nocodeveloper. Para la versión final se usan fotos e información reales del negocio.
